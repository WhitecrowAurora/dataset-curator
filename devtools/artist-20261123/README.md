# 画师表配发与旧产物补注入

服务器支持给仓库设置画师表目录和固定 HF revision，任务领取时冻结注入配置。
中心按分片读取、验证并缓存画师表，客户端沿用已有 TAG / 中英文 NL 前缀格式。
离线派单包内嵌对应画师映射。新包必须更新客户端；旧离线包需要重新导出。

管理员入口：工作区的高级任务设置 → 画师表与任务注入。旧中心结果在工作区选中
分片后点补注入选中／强制重新注入选中；本地历史结果可在设备托管候选上下发
对应命令。客户端入口：调度中心 → 本地已做结果 → 每包的补注入按钮。
所有补注入均不运行模型，保留备份、失败状态和管理员冲突决议。普通模式补缺失
前缀，强制模式替换能确认旧画师元数据的前缀；未知前缀不能自动猜测。
