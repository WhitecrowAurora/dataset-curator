# 管理面板交互整理 · 2026-11-24

已部署到当前服务器管理面板。成员客户端无需更新。

## 管理员入口

进入工作区后按用途切换：

| 分类 | 内容 |
| --- | --- |
| 概况 | 当前工作区分包统计和仓库进度 |
| 派单 | 三步在线预派助手、高级手动/设备/分项分配、已分配派工表导出 |
| 结果与核验 | 分包选择、结果下载与分享、逐图核验、冲突处理、画师补注入、离线结果导入确认、已有离线清单下载与取消 |
| 设置 | 编辑工作区和成员、默认模板、仓库许可、源清单设置、画师分表 |

在线助手默认带入上次成功派单配置或工作区模板。常规流程为“选择成员 → 选择分包 → 核对预派单”；模型、引擎、并发、打标模式和画师注入可展开“本次打标配置”修改。保存仍调用原预派单接口，实际领取后才开始计算租约。

顶部“离线工单”保留为独立功能，地址 `/offline-workorders`。派单页提供带工作区参数的跳转。工作区中重复的离线生成表单已移除，离线回收继续位于“结果与核验”。此前已生成的离线工单和独立页面保持兼容。

工作区详情中收起工作区总列表，通过“返回列表”切换。分类切换保留选择和表单状态；自动刷新不会替换正在编辑的内容。已完成分包可在结果页勾选下载与核验，派单页仍限制不可派分包。
