快速开始（服务端）:
  python3 server.py repo add --repo org/name --repo-type dataset
  python3 server.py serve --host 0.0.0.0 --port 31831
  python3 server.py enroll --name alice

快速开始（v3 客户端）:
  python3 worker.py login --server http://IP:31831 --user-id alice
  python3 worker.py run --cmd 'tagger ... {shard}'
