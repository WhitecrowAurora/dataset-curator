## 修改

- HTTP 错误保存状态码、错误说明和逐图明细。永久 4xx（408／429 除外）停止自动重试，临时网络错误保留自动补传。401／403 和租约 409 使用各自退出码。
- `.fox-delivery.json` 按当前源和租约持久化上传、验收、登记与失败状态；重启可继续查看原因。日志及 UI 区分文件上传完成、中心逐图验收和整片登记，缺项不显示整片完成。
- 心跳覆盖执行、上传、归并和最终申报；收到租约撤销后停止申报和长退避。上传阶段中断也归还当前执行租约并保留本地产物。
- 恢复计时、显式开始和中心暂停统一到托管控制器；仅等待重启的状态可以显式恢复，正在运行／准备／历史检查／并发调整仍按原状态处理。租约失效和永久验收拒绝不再触发看门狗循环。
- 管理员释放包、租约和设备使用同一个事务内关闭流程，释放分项／定向队列、更新 offline 工单和包状态、暂停原设备并下发 stop。保留已验收侧和产物，旧 start 指令保留序号但取消未接收项。预览显示实际包、租约和受影响设备数量。
- 暂停按设备策略检查，不再因托管会话已退出而允许旧接口新领包；真正新登记／换账号时清除原身份的暂停策略，保留同一身份的重连暂停。该兼容问题是在本轮收尾实测发现并修正的。
- Shell 和命令入口优先加载当前工作目录，CLI 修正本包嵌入 Python 的 `_tagger_repo.pth` 为相对四级路径。只修改包自己的解释器，不改共享 trainer 环境。Shell 仍只负责定位和启动，模型及 WebUI 业务留在 Python。
- 独立 worker 重新同源生成，29 份内嵌源码已核对。客户端正式交付的窗口程序仍自带 .NET 运行时；之前的 Torii/Transformers 兼容修复保留。
