## 使用方式

- 概览的仓库行点击“画师注入与分表”，或进入工作区的“编辑”弹窗，在“画师表与任务注入”中设置。
- 点击“识别仓库画师分表”，选择识别结果，再点击“使用所选目录与版本”。此操作只填入目录和固定 HF 版本，不自动启用或保存。
- 确认“启用画师表”与独立的 TAG／NL 注入开关，点击“保存画师配置”。工作区总“保存”只更新名称与仓库列表；画师配置按仓库保存，同仓库其他工作区也生效，界面已明确说明。
- 既有工作区详情的高级入口改为“设备、分项分配、画师表与核验详情”；派单继承文案明确为“沿用仓库设置（未配置时沿用客户端）”。

格式沿用现有客户端：TAG 为 `@画师, 标签`，英文 NL 为 `In the style of @画师, 描述`，中文 NL 为 `使用 @画师 的风格，描述`。已领取的任务继续使用领取时固定的配置；旧产物使用既有“补注入选中”或“强制重新注入选中”功能。
