# 新用户默认接单与占用筛选

2026-11-24 完成并部署。服务器地址沿用现有中心。

## 默认接单

连接后自动接单默认开启，使用本机执行配置。身份注册仍不领包；登录成功后进入执行流程。

未归属、无现有任务或指定范围的用户加入最近创建且有可领取分项的自动工作区，沿用原分项选择、租约与唯一索引。已配置的账号、设备及用户组归属保留。已持有租约、手动队列、设备分派表和直接指定保留原范围。

被动托管的主动暂停不会因连接或重启撤销，新增“恢复自动接单”复用原开始接口。恢复意图持久化到原托管记录，断网后重送，旧请求确认不会清掉后来点击的新恢复请求。主动模式连接时读取服务器暂停策略，不自动启动已暂停设备；显式开始仍由用户选择。

服务端上线文件：dispatch.py、managed/store.py、scheduling/onboarding.py。
备份：`/tagger/.delete/auto-workspace-20261124/before`。
