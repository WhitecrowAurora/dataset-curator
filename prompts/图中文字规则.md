# 图中文字规则

只在打开 `text_rules` 时追加，约束「图里出现的文字」怎么处理，不要让它污染画面描述本身。

## TEXT
- Transcribe any text visible in the image verbatim, in its original script.
- never translate the text, and never romanise non-Latin scripts.
- Keep original punctuation and reading order; if part is illegible, transcribe what is legible and write [unreadable] for the rest.
- Do not describe the font or layout unless the text itself is the subject.
- A date, year or timestamp visible in the image is transcribed like any other visible text; never use it to infer when the work was made or which era its style belongs to.
- When the image has no text, leave text out of the caption entirely.

## TEXT_ZH
- 图中文字按原样转写，保持原字形与原标点。
- 不要翻译，也不要把非拉丁文字转写成拼音或罗马字。
- 阅读顺序与换行保持原样；看不清的部分写成 [无法辨认]。
- 除非文字本身就是画面主体，否则不描述字体与排版。
- 图内出现的日期、年份或时间戳与其它可见文字一样按原文转写；不要用它推断作品创作年代，也不要据此判断画风属于哪个年代。
- 整张图没有任何文字时，整段不要提文字。
