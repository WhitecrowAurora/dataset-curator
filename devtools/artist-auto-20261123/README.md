## 最终行为

- 历史补注入已有画师表配置时先读取固定来源；目录没有配置，或固定版本内配置路径返回 404 时，自动发现同仓库内对应分片的 `*.artist.parquet`。只有唯一有效目录才自动用于本次检查；样本使用本次真实分片，并最终校验标记。多目录／重复分片名不猜选。
- 已明确禁用仓库或分项不自动开启；保留管理员 NL/TAG 选择。读取失败或权限问题不视为目录缺失。自动查找不会保存仓库新默认值或改已有租约，只把固定 source 冻结到本次历史检查。
- 补注入等待网络结束后再次核对仓库配置、分项开关、源分片 SHA／大小、托管会话及占用，避免读取期间变化后创建旧任务。
- 同名重复前缀合并为一个；旧前缀仅含表中部分作者时按表补齐。强制模式可移除完整的既有画师句，按图片 ID 对应表中画师重新注入。名字保留原拼写，不从模型或普通正文推断画师。
- 缺失模式发现不同画师／格式不完整，保留原条目，逐条报告图片 ID、原前缀、表中画师。其余成功补注入的文件有原始备份并保留，不因单条冲突丢失。存在待核对时不回传这包，待核对后可按表强制重新注入；畸形且无法确认正文边界的前缀仍需要人工核对。
- 页面“任务与记录 → 本地已做结果”显示上述详情。局部文件变化后的报告使用新 fingerprint 保存，刷新仍能看到待核对信息。日志打印本次画师表来源。
