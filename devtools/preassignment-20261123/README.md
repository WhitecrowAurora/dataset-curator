# 按用户预派单与管理员快速配置助手

2026-11-23：已部署到当前调度中心 `http://119.28.16.93`。

## 使用

管理员刷新网页（Ctrl+F5），进入「工作区」，选择工作区后点击顶部「快速配置与预派单」。四步依次选择成员、打标配置、分包，再核对保存。

- 已注册成员可以暂时离线或没有登记设备；未归属工作区的成员可在助手保存时加入当前工作区。
- 默认沿用成员本机配置，可指定模型、引擎、NL 并发和 TAG 批大小，以及本次分包的画师注入选项。手动仓库分配模式下，助手同时保存所选成员的仓库许可，未来设备沿用该用户许可。
- 指定执行配置是领取条件；不会自动更换成员的本机模型。不匹配时等待并提示成员退出托管后调整配置，再开始托管。0 并发／批大小不限制本机自动值。
- 预派单保存时不创建租约；成员上线托管、配置与能力匹配后，经原有事务领取，再开始计算 48 小时租约。只连接服务器不等于启动打标；主动暂停保持暂停。
- 已完成、正在执行、预锁、待冲突处理或已有其他指定的分项不抢派；整批保存失败会回滚。多位成员间按已分配数量均衡，同包分项尽量交给同一成员。
- 原工作区派单也支持按用户预派，仍可切回指定设备。高级选项可取消选中分包尚未领取的用户预派。
- 按用户／包名排序的分派表及每用户 ZIP 导出保留，指定预派配置随导出保存。
