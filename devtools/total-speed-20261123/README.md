# 调度中心顶部总速度

网页顶部常驻「总速度」：张/秒、张/分钟、上报速度设备数／当前执行设备数。所有页面可见，每 5 秒刷新，隐藏窗口暂停网络读取，切回立即刷新，手动刷新也更新速度。鼠标悬停显示统计口径及 TAG／NL 分项速度。手机顶部固定三行，吸顶偏移与实际顶部高度一致。

复用现有 `/admin/v1/managed/devices?summary=throughput` 和面板对应代理接口。专用查询只读取执行租约、设备身份及托管进度，避免为顶部每次加载全部设备能力、历史指令、任务记录。没有改派工、模型或心跳协议，没有数据库迁移。

总速度是最近上报的分包内平均有效速度之和，按图片结算；不会把同一设备的 TAG 与 NL 各算一遍。只统计有效 active 租约，排除心跳超过 120 秒、租约过期、已停止／准备中、用户停用和设备屏蔽。进度超过 120 秒不计速度，显示待速度设备数；未报告速度的设备同样显示为待速度。网络读取失败显示「—」，恢复后自动更新。离线打标无法联网报告，暂不计入此统计。

验证：15 项定向测试全部通过，覆盖双分项不重复、断联／停机／准备中／过期、无效数值、过期进度、托管与租约对应、设备去重及只读查询。真实隔离中心与 Edge 验证 1.25 张/秒对应 75.0 张/分钟、切页面与滚动顶部常驻、手机无横向溢出、吸顶高度匹配、过期速度排除和网络恢复，0 页面错误。服务器数据库副本查询和上轮分派导出回归通过，真实租约未被测试修改。
