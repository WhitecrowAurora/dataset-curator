## 已修复

- 缺少 Qwen3.5-0.8B 训练 tokenizer 时，本机新任务、调度开工、离线打标及命令行客户端提前报出可操作提示，不等逐图处理中才失败。沿用“冲突与审查”的 tokenizer 准备功能；TAG 单模式不要求该 tokenizer。

- NL 服务进程退出时使用实际引擎名称和日志路径，启动失败附日志尾巴。以前通用生命周期写死“vllm”，该文案不能证明选择 native 后实际切换了引擎。
