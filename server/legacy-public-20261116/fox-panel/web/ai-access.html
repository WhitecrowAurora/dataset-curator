连接方式

支持 MCP Streamable HTTP。AI 客户端填写下面的地址，并在请求头配置 Authorization: Bearer 密钥。

可查询工作区、分片、完整调度配置、设备速度、显存、等待原因；操作权限支持预派单和撤销预派、自动派单启停、强制继续、并发调整、探测、租约释放以及离线工单生成和删除。所有操作仍受原调度规则约束。

撤销预派只取消尚未领取的用户分项；执行包和预锁包请先预览再释放。撤销不会暂停自动派单，若不希望重新分派，应先暂停总派单。更新后请重新连接 AI 客户端刷新工具列表。

若 AI 客户端只支持本地 stdio，可使用配套 Python 桥接脚本。下载桥接脚本和配置说明（Python 3.10+，无需安装依赖）。
