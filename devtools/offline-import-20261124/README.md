# 离线工单与网页确认回收 · 2026-11-24

已部署到当前调度中心。顶部新增“离线工单”，独立页面路径为 `/offline-workorders`。

## 管理员生成工单

1. 选择工作区，查询分包状态；可搜索、加载更多、勾选可分配的包。
2. 把分包加入成员草稿，分别保存每位成员的模型、引擎、并发和画师注入配置。
3. 草稿保存在当前浏览器，刷新保留；编辑与查询不会占用分包。
4. 核对后点击“登记并生成工单”，由服务器登记离线分配，再下载各成员 JSON。

确认生成时会重新检查服务器分包状态。多人分批生成中，已成功生成的工单保留，失败部分留在草稿中；不要重新分配已成功生成的包。已有工单可在页面重新下载。

## 成员导出与管理员回收

成员关闭客户端后覆盖本轮新包。在“调度中心 → 任务与记录 → 离线已分配任务”导入工单、完成离线任务。停止执行后点击“导出网页回收包”，把 ZIP 交给管理员。已有成功产物无需重新打标；导出仍需能读取原分片素材以生成校验证明。

管理员进入原工作区页面的“导入离线结果并确认回收”，上传 ZIP、查看逐片预览、选择可回收的片、勾选核对确认，再确认回收。仅上传与预览不会登记完成。结果仍归原工单成员，重复确认不会重复完成；缺项、失败、冲突片需要先处理。

单次上传上限 64 MiB；可以在客户端选择单片导出，分批上传。待确认上传保留 24 小时，目录总量上限 256 MiB。回收包不含原始图片。源总表尚待核验时，齐全结果只登记为“待核验”；未启用源总表的仓库沿用现有客户端证明契约。
