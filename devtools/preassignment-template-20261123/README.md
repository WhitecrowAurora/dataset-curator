## 行为

- 按工作区保存打标内容、沿用本机／指定模型与并发、TAG/NL 配置和画师注入选项。
- 快速助手带入模板，本次编辑优先；普通按用户预派在未指定执行配置时使用模板。
- 保存、修改和清除模板不创建派工或租约，不改既有派单；实际派单保存当时的配置快照。
- 指定模型与并发仍是领取要求；不匹配的设备需调整本机配置后领取，不会远程替换模型。
- 设备派单和离线清单沿用原有执行设置，不套用用户预派模板。
- 模板未设置时保留原有派单默认行为；新成员不会因为模板存在而自动获分包。
