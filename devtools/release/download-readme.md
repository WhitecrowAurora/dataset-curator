解压到可写目录，运行 install.bat，再启动 Tagger.Shell.exe。模型和 GPU 依赖需安装／下载；本包有 Python 初始化材料，不含本机完整环境。Linux 使用 install.sh 与 run-web.sh，桌面 exe 仅适用于 Windows。

在调度中心保存模型、设备、精度、目录和凭据后，选择主动模式或被动托管。选择被动模式后另点开始托管，执行环境冻结；中心自动安排工作区任务并下发开始／停止／历史检查，本机可退出托管。管理员可分组、配置仓库优先级和分别指定 TAG／NL。工作区的分配模式默认自动；切到手动后逐仓库选择设备，未分配设备等待。切换保留执行，释放不再符合分配的预锁并清理旧指定；主动和被动共用分项租约。管理员不能覆盖本机模型环境。

自动回传分别记录各分片 TAG／NL 成功、最终排除、失败、漏项和完成状态。不同设备可同时处理同一分片的不同侧，已有结果按源 SHA256 归并并用于增量续作；中断可回传半成品。失败、漏项和冲突不能登记该侧完成。离线宽限只释放未开工预锁，执行租约保留供管理员回收。

历史手动产物先关联原片与产物目录，再由面板下发逐图检查，支持 JSONL、JSON 和 Parquet。未上传逐图证明的旧完成记录显示未验收。面板刷新分片可查看最新计数。

中心支持按仓库配置独立图片清单：JSONL／JSON／Parquet 总表、分片索引或按需扫描原片。缺少中心清单时回传进入待核验，后台通过后登记完整侧，设备可继续下一片。400k 已启用，第一片 10,940 张图片核对通过；其它仓库需核对清单字段与输出分片映射。

升级前关闭旧客户端，将程序覆盖到原目录；包内不包含个人配置、Token、身份、模型与工作目录。保留原机数据，自行修改的内置提示词和 tiers.yaml 请先备份。

独立 worker 需要 Python 3.10+ 和 curl；无需 pip，自定义打标命令环境另行安装。示例：python worker.py login --server http://119.28.16.93 --user-id YOUR_NAME；python worker.py run --help。被动托管请使用完整客户端。
