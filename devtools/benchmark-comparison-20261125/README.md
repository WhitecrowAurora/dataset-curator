# 模型、引擎叠加对比

2026-11-25，工作区 H:\tagger。在已有并发测试页面上扩展，入口仍为侧栏「环境 → 并发测试」。

## 功能与页面

- 使用 A/B 配置卡，分别选择已准备好的模型、可用引擎、已有精度；支持单配置测试以及最多四组对比。同一模型可切换引擎，也可对比不同模型或精度。
- 默认并发为 1、2、4、6、8，保留扩展到 24 和自定义档位。各配置共用一份固定样本，依次启动、预热、测速、释放模型服务，避免同时占卡。
- SVG 叠加折线图使用线性坐标：横轴为实际并发，纵轴为张/分钟。点击图例显示/隐藏曲线；悬停或键盘聚焦数据点可查看同并发下各配置的速度。没有补造成功点，失败处断线。
- 每组独立显示峰值速度、建议并发、成功档位；详细耗时、显存、错误放入可展开表格。旧单模型报告与请求仍可读取。
- 采用石墨灰与橙/青曲线，卡片颜色和图例一致；兼容深浅主题。小于 540px 时仅在本页面将既有侧栏收为图标栏，保留导航按钮可访问名称。
- 报告包含配置、series_id、各档实际值和独立输出路径。停止保留已完成曲线，取消后不会继续下一配置；失败档不会阻止其他配置测试。
