# 调度中心代理连接（2026-11-23）

调度中心「连接与账号」新增自动（系统代理）、直连、指定代理，默认保持自动。指定代理接受 HTTP / HTTPS 地址和端口，例如 `http://127.0.0.1:47826`；使用代理软件的 HTTP 或 mixed 端口。代理设置保存在本机，不能由服务器下发，不进入设备身份或托管执行配置。

登录、状态/池子/工作区、托管轮询、worker 接单/心跳/申报、续做快照、产物回传、历史核对和离线补传共用此设置。子进程按调度服务地址传递网络策略，其他来源的素材下载保持原网络设置，本机推理保持直连。明确指定代理时不受系统 NO_PROXY 排除；直连时不使用系统代理。调度身份请求不跟随重定向。

实现集中于 `tagger/center_runtime/network.py` 和 `ConnectionNetwork.tsx`，已有各通道接入，无新入口。独立 worker 同源生成并加入网络模块。
